# Примеры 1С

Официальные примеры из описания стандарта 1С:DirectBank. Файлы скопированы без изменений.

- Электронные документы, версия 2.3.2 — <https://github.com/1C-Company/DirectBank/tree/2.3.2/doc/application-layer>:
  `CancelationRequest.xml`, `PayDocRu.xml`, `PayRequest.xml`, `Probe.xml`, `Settings.xml`, `Settings_Logon_Certificate.xml`,
  `Statement.xml`, `StatementRequest.xml`, `StatusDocNotice.xml`, `StatusRequest.xml`
- Из описания транспортного протокола, версия 2.2.2 — <https://github.com/1C-Company/DirectBank/blob/2.2.2/doc/transport-api/readme.md>:
  - `GetSettingsResponse.xml` — пример ответа на GetSettings
  - `Packet.xml` — пример запроса SendPack. Подпись в примере обрезана и не является корректным base64, поэтому XSD файл не проходит.
