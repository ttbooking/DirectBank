# Примеры 1С

Официальные примеры из описания стандарта 1С:DirectBank, версия 2.2.2.
Файлы скопированы без изменений.

- `Statement.xml`, `StatementRequest.xml` — <https://github.com/1C-Company/DirectBank/tree/2.2.2/doc/application-layer>
- `Packet.xml` — пример запроса SendPack из <https://github.com/1C-Company/DirectBank/blob/2.2.2/doc/transport-api/readme.md>.
  Подпись в примере обрезана и не является корректным base64, поэтому XSD файл не проходит.
